# Getting Started

This guide describes the lifecycle for integrating AfriPay into a web application.

## Integration lifecycle

1. Create an AfriPay Business account.
2. Complete any account or business verification required by AfriPay.
3. Prepare the payment integration in your application.
4. Create a publicly accessible webhook/callback URL.
5. Request production `APP_ID` and `APP_SECRET` credentials from AfriPay.
6. Provide the callback URL to AfriPay for registration.
7. Store the credentials securely as environment variables.
8. Complete an end-to-end production payment test.
9. Go live.

## Prerequisites

- An AfriPay Business account
- A web application with a backend
- A public HTTPS webhook endpoint
- AfriPay production credentials

Continue with [Account and Credentials](account-and-credentials.md), then use the main [Integration Guide](../README.md).
